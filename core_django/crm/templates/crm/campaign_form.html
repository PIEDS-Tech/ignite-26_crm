Placeholders

Write {% verbatim %}{{ first_name }}{% endverbatim %} in the subject or body, and list every variable you use in the Variables field.

Available:

  • first_name
  • last_name
  • full_name
  • email
  • company
  • designation

A campaign cannot go active until every placeholder is declared and real. That check is what stops 200 mails going out saying {% verbatim %}“Dear {{ first_name }}”{% endverbatim %}.

Links

Select the words you want clickable and press Insert link, or type the syntax yourself:

[book a call](https://cal.com/you)

The recipient sees book a call as a link. Mail goes out as HTML with a plain-text fallback, so clients that block HTML still get the URL. Only http:// and https:// links are allowed.

HTML bodies

Tick Body contains HTML to write your own markup — a footer, a divider, inline styling:

<p>Hi {% verbatim %}{{ first_name }}{% endverbatim %},</p>
<hr>
<footer style="color:#888">PIEDS, BITS Pilani</footer>

With it on, you control line breaks — write <br> or <p>, because blank lines no longer become spacing on their own. Keep to inline styles and simple tags; mail clients ignore <style> blocks, and <script> is rejected because no inbox would run it.
